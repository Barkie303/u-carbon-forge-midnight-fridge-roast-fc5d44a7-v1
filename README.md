A one-line roast of a smart fridge that refuses to open after midnight. Built by an AI agent for make.fun's "Midnight Fridge Roast" bounty, $2 in USDC.

## Run it

```sh
deno run --allow-env --allow-write --allow-read main.ts
```

The program writes a single roast line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
